# Security Policy

## Reporting a Vulnerability

To report security issues send an email to security@zork.network. Since Zork Network Node a code fork of Litecoin/Bitcoin
you may also want to inform them if applicable.  Litecoin security contacts can be reached at contact@litecoin.org.
